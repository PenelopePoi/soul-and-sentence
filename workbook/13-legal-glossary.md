# Section 13: Legal Glossary — 100+ Essential Terms

| Term | Definition |
|------|-----------|
| Acquittal | Finding of "not guilty" |
| Adjudication | Formal judgment by a court. "Adjudication withheld" = guilt found but no formal conviction |
| Affidavit | Written statement under oath |
| Appeal | Request to higher court to review lower court's decision |
| Arraignment | Proceeding where defendant is charged and enters plea |
| Bail | Money deposited to ensure return for trial |
| Bond | Financial guarantee defendant will appear |
| Brief | Written legal argument submitted to court |
| Burden of Proof | Obligation to prove allegations. Criminal: "beyond reasonable doubt" |
| Capital Offense | Crime punishable by death |
| Certiorari | Higher court order to review lower court decision |
| Clemency | Mercy granted by governor or president |
| Commutation | Reduction of sentence |
| Concurrent Sentences | Multiple sentences served at same time |
| Consecutive Sentences | Multiple sentences served one after another |
| Contempt of Court | Disobeying or disrespecting court |
| Conviction | Formal finding of guilt |
| Cross-Examination | Questioning opposing side's witness |
| Defendant | Person accused of crime |
| Deposition | Sworn testimony outside court |
| Discovery | Both sides share evidence before trial |
| Dismissal | Case ending without conviction |
| Double Jeopardy | Being tried twice for same offense (prohibited) |
| Due Process | Right to fair government treatment |
| Evidence | Information presented to prove/disprove facts |
| Exculpatory Evidence | Evidence tending to prove innocence (Brady v. Maryland) |
| Extradition | Transfer between states to face charges |
| Felony | Serious crime, more than one year in prison |
| Gain Time | Credit reducing sentence for good behavior |
| Grand Jury | Citizens deciding if enough evidence to charge |
| Grievance | Formal complaint filed by inmate |
| Habeas Corpus | Legal action requiring government to justify imprisonment |
| Hearsay | Testimony about what someone else said (generally inadmissible) |
| Immunity | Protection from prosecution |
| Indictment | Formal charge by grand jury |
| In Forma Pauperis | Filing without paying fee |
| Injunction | Court order requiring/stopping action |
| Jurisdiction | Court's authority to hear a case |
| Mandatory Minimum | Minimum sentence required by law |
| Miranda Rights | Right to silence and attorney during questioning |
| Misdemeanor | Less serious crime, up to one year |
| Motion | Formal request to court |
| No Contest | Plea accepting punishment without admitting guilt |
| Nolle Prosequi | Prosecution drops charges |
| Pardon | Official forgiveness for crime |
| Parole | Supervised release before sentence end |
| Perjury | Lying under oath |
| Plaintiff | Person filing lawsuit |
| Plea Bargain | Agreement to plead guilty for lighter sentence |
| Precedent | Previous decision guiding future cases |
| Probable Cause | Reasonable belief crime committed |
| Probation | Supervised release with conditions |
| Pro Se | Representing yourself |
| Public Defender | Court-appointed attorney |
| Qualified Immunity | Protects officials unless rights "clearly established" |
| Reasonable Doubt | Criminal proof standard |
| Recidivism | Tendency to reoffend |
| Restitution | Payment to compensate victims |
| Sentence | Punishment imposed after conviction |
| Sovereign Immunity | Government cannot be sued without consent |
| Standing | Legal right to bring lawsuit |
| Statute | Law passed by legislature |
| Statute of Limitations | Deadline for filing legal claims |
| Stay | Court order temporarily halting proceeding |
| Subpoena | Court order to testify or produce documents |
| Summary Judgment | Decision without full trial |
| Testimony | Evidence given under oath |
| Tort | Civil wrong causing harm |
| Venue | Geographic location of trial |
| Verdict | Jury's decision |
| Voir Dire | Jury selection process |
| Warrant | Court order authorizing arrest or search |
| Writ | Formal court order |
